# Contributing to nixeljam

Everybody is invited and welcome to contribute to nixeljam. There is a lot to do... Check the issues!

The process is straight-forward.

- Read [How to get faster PR reviews](https://github.com/kubernetes/community/blob/master/contributors/guide/pull-requests.md#best-practices-for-faster-reviews) by Kubernetes (but skip step 0 and 1)
- Fork nixeljam [git repository](https://github.com/milotek/nixeljam).
- Write your changes (new theme, bug fixes, issues fix, ...).
- Create a Pull Request against the main branch of nixeljam.

> [!IMPORTANT]
> Don't push your host's folder
